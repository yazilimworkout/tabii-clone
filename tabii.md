# Tabii | Turkish Series

Build a Turkish series discovery site with Vite, React, and TypeScript. Do not return only a design or plan: set up the project, implement every page and interaction, then run a production build.

## Required user setup questions

Before editing files, ask for Discord, YouTube, X, Instagram, and Reddit URLs one at a time in `Type answer` prompts; accept `skip` for social URLs. Use the supplied social URLs in the site and keep skipped social icons visible without links.

After implementation, show a dismissible dialog once with: `Thank you for using the Tabii prompt!`

## Setup order and completion gate

1. From an empty project root, run `npx shadcn@latest init -t vite` to create a Vite app using React, TypeScript, and Tailwind CSS. When the CLI asks, choose the Vite template, Luma style, `mist` base color, and Tabler icons.
2. From the project root, run `npm install react-router-dom @tanstack/react-query @tabler/icons-react motion @reduxjs/toolkit react-redux redux-persist tailwind-scrollbar-hide swiper`. Then add the required shadcn/ui components with `npx shadcn@latest add button card badge aspect-ratio input label select dropdown-menu navigation-menu sheet dialog skeleton scroll-area tooltip avatar spinner --yes`. If a command fails, resolve the error and add any missing components before building the app.
3. Inspect `package.json`, `components.json`, and `src/components/ui/`. Merely listing packages in this prompt is not enough: dependencies must be installed, shadcn component files must exist, and the app must import and use them.
4. After implementation, run `npm run build` and fix any errors. Never claim a command ran if it did not; report the main installed packages and actual build result briefly at the end.
